Why might this fail? (Same Origin Policy explained simply)

Your browser treats every website as a separate, locked room. A page from one website is not allowed to look inside a page from another website – even if both are open in your browser at the same time. This is called the Same Origin Policy.

This test page and the lunch system (http://194.160.223.198) are different "rooms", so the browser should refuse to let this page read the meal list. That is a good thing: it is the same protection that stops a random website from reading your e-mail or bank account.

If access is blocked, the realistic options are:

  • Chrome extension – what SUF Obedník already is; it runs inside the lunch page with permission.
  • Mobile app with a WebView – the app loads the lunch page itself and injects JavaScript into it.
  • Bookmarklet / userscript – a small script the user runs while the lunch page is open, so it runs inside that page.
